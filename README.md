# Tron

Dictée vocale et transcription sur l'appareil. Votre voix ne quitte pas l'appareil.

| Plateforme | Dossier | Langage |
| --- | --- | --- |
| iOS | [`ios/`](ios/) | Swift, SwiftUI |
| macOS | [`macos/`](macos/) | Swift, SwiftUI, AppKit |

Chaque app est écrite dans le langage natif de sa plateforme.
